# Как решаются ЖК, точка и район (13.10.2026; итог правок — в конце)

## 1. Новое объявление (ingest.save_object), по порядку
1. **Разбор текста** (`parser`/`rules`/`geo`): улица, дом, ЖК, район, посёлок — только то, что есть в тексте;
   ЖК → район по справочнику ЖК; нет района, есть улица → район по справочнику улиц (`geo.district_by_street`).
2. **Опечатка улицы** (`osmaddr.fix_street`) — по справочнику домов OSM.
3. **Выученные правила** (`learning.apply`), каждое следующее перезаписывает предыдущее:
   1) псевдоним ЖК (`cx_alias`) → правильный ЖК;
   2) улица → район (`street`) — если района нет, он угадан по улице или улицу «перенесли» из этого района;
   3) ЖК → район (`cx_district`) — **перезаписывает район из текста объявления безусловно**;
   4) дом → ЖК и район (`addr`) — самое конкретное, последнее.
   Ключ улицы/дома = посёлок (`settlement`) + улица (+ дом). У объектов Краснодара и его микрорайонов-посёлков, где
   `settlement` пуст (Знаменский, Яблоновский как район), ключ без посёлка → одна «Гагарина» на всех.
4. **Одно название ЖК** (`cxnorm.canonical`, P1.7) → склейка повторов (`dedupe`) → сохранение.

## 2. Точка (worker: autolearn.run → geocode.run, раз в цикл)
`autolearn.Known.point`, первое найденное:
1. ваша точка дома/ЖК (`geocode.learned_point`, ключи `addr:` и `cx:`) → `learned`;
2. тот же дом в фиде СТРЕЛ (`feed-house`);
3. дом в справочнике OSM (`osm-house`, соседний номер — `osm-near`) — если не спорит с ЖК/районом;
4. **центр ЖК** (контур ЖК `map-cx` или середина объектов фида `feed-cx`) — с `geo_status = 'ok'`, т. е. **как точная**;
5. середина улицы OSM (`osm-street`, примерная);
затем Nominatim (`geocode.run`, проверка `plausible`), район без дома → центр контура района (`map-district`, примерная).

## 3. Район после точки
- `geocode.run`: нет района, есть точка → район по контуру (`_district_from_map`).
- `autolearn.fill_districts` (каждый цикл): нет района → «карта» + «голоса» того же дома / ЖК; спорят — в «Спорные».
- `autolearn.recheck_all` (раз в час): точка дома в другом контуре дальше 150 м от района из текста → район по карте
  (журнал `listing_edits`, user_id 0); **если у объекта есть правило (дом/ЖК/улица) — правило побеждает**, расхождение
  только помечается «Спорные»; квартира без ЖК в контуре ЖК → ЖК. Откат — только весь разом (`rollback_recheck`).

## 4. Кто кого перезаписывает (итог)
правка админа (`admin_fixed`) > правило дома > **правило ЖК > правило улицы > текст объявления** > контур под точкой.
Карта районов решает район только когда района нет или нет правила — отсюда «4 % по карте» из аудита и случаи, когда
текст и контур совпадают, а побеждает неверное правило («Кирилла Россинского» вместо «Петра Метальникова»).

## Что меняем по ТЗ (порядок)
P0.0 чистка правил (отчёт → «Применить» в админке) · P0.0.1 новый приоритет: админ > дом > контур под точкой-домом >
правило ЖК > текст > правило улицы · P0.1 безопасное обучение · P0.2 Enter/кнопки · P0.3 журнал и откат по объекту ·
P0.4 баги · P1 справочники · P2 уровень точки (`geo_level`) · P4 удобство. P3 (склейка) — не трогаем.

## Как стало после ТЗ «админка-гео» (13.10.2026)

**Район** (от главного): правка админа (admin_fixed) → правило «дом → район» → контур под точкой уровня «дом»
(`learning._house_district`, `search.geo_level == "house"`) → правило «ЖК → район» → текст объявления →
правило «улица → район» (только если нет ни района в тексте, ни точки дома). Точка ЖК / улицы / района район не решает.
Перепроверка (`autolearn.recheck_all`) меняет район сама не больше чем у max(2 %, 10) объектов за прогон — иначе
«Спорные» + уведомление. Каждая автоправка — `listing_edits.src` («перепроверка», «чистка правил»), откат по объекту.

**Точка** (от главного): ваша точка → выученная точка дома → тот же дом в фиде → дом в справочнике OSM → поиск дома
по адресу (Nominatim) → выученная точка ЖК → центр контура ЖК / середина фида ЖК → «ЖК …» поиском → середина улицы
/ посёлок → центр района. Уровень точки (`search.GEO_LEVEL`, по geo_src): house / complex / street / district / none.
На карте: house — меткой; complex — одной меткой «ЖК · N»; street/district — не меткой («адрес уточняется»).
В подборке клиенту — только house. Ручная точка дома больше не становится «центром ЖК».

**Проверка и отчёты:** /learn → «Проверка правил и справочников» (`app/geoaudit.py`: правила против карты, ЖК-мусор,
улицы-подписи, испорченные правила, точки домов без посёлка по справочнику адресов, точки ЖК из одного дома,
районы-дубли; всё — галочками и «Применить отмеченное»), «Качество данных» (`app/geoquality.py`, снимок раз в сутки,
отчёт раз в неделю), «Насколько сервис прав» (выборка до 40 решений в день на источник, `brain.accuracy`).
Консоль: `python -m tools.geo_audit [база]`. Склейку повторов (P3) не меняли.
