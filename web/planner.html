    Календарь телефона

    Подпишитесь один раз — показы и созвоны из планера сами появятся в календаре телефона и будут обновляться.

    iPhone: нажмите здесь → «Подписаться». Или: Настройки → Календарь → Учётные записи → Новая → Другое → «Подписной календарь» → вставьте ссылку.

    Android (Google Календарь): откройте calendar.google.com на компьютере → «Другие календари» → «+» → «Добавить по URL» → вставьте ссылку. Google обновляет такие календари раз в несколько часов.

    Ссылка личная — не пересылайте её никому.
