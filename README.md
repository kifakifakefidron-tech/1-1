# 1+1 ➳ поиск объектов

Сайт, где можно искать квартиры, новостройки, дома, участки и коммерцию Краснодара,
которые риелторы присылают в чаты WhatsApp / Telegram / MAX.

Как это работает:

1. **worker** каждые 1–2 минуты забирает новые сообщения из Wappi (только читает по API —
   настройки Wappi и рассылка не затрагиваются).
2. Каждое сообщение разбирается: нейросеть DeepSeek (один запрос на сообщение) +
   проверка правилами. Если ключа DeepSeek нет — разбор только правилами.
3. Одинаковые объекты от разных агентов и из разных чатов склеиваются в один.
4. **web** — сам сайт: поиск, фильтры, карта, карточка объекта.
   Покупатели видят общий контакт, коллеги после ввода кода — телефоны агентов.
5. **caddy** — «входная дверь»: принимает посетителей и сам получает HTTPS-сертификат.
6. **bot** — Telegram-бот: вход на сайт с подтверждением номера, «убрать мой номер»
   для агентов, уведомления владельцу о сбоях.

Личный кабинет: вход через Telegram или по почте, избранное. Номера агентов видны
только с доступом: неделя бесплатно после подтверждения номера (раз на номер), дальше
подписка. Админка — `https://<адрес сайта>/admin` (вход через Telegram владельца).

Работает на **отдельном сервере** (Timeweb Cloud, Ubuntu 24.04) — старое приложение
с рассылкой никак не затрагивается. Всё хранится в одном файле `data/strely.db`.

## Установка (один раз)

Все команды вставляются в окно SSH на новом сервере.
Вставить в окно терминала — правая кнопка мыши.

### 1. Подключиться к серверу

На своём компьютере откройте PowerShell и выполните:

```bash
ssh root@31.130.132.118
```

Пароль — из карточки сервера в Timeweb (при вводе он не отображается — это нормально).
Можно и без PowerShell: в карточке сервера в Timeweb есть кнопка «Консоль».

### 2. Скачать проект и подготовить сервер

```bash
git clone https://github.com/kifakifakefidron-tech/1-1.git /opt/1plus1
```
```bash
cd /opt/1plus1 && bash setup.sh
```

`setup.sh` ставит Docker, создаёт папку для базы и файл настроек `.env`,
включает защиту (открыты только SSH и сайт). В конце пишет адрес сайта.

### 3. Вписать настройки

```bash
nano .env
```

- `ACCESS_CODE` — код для коллег (можно по-русски);
- `PUBLIC_CONTACT` — куда пишут покупатели;
- `DEEPSEEK_API_KEY` — ключ с platform.deepseek.com (можно позже);
- `WAPPI_TOKEN` и `WAPPI_PROFILES` — **можно оставить пустыми** на первый запуск:
  сайт заработает, просто без новых объявлений. Подключим отдельным шагом.

Сохранить: `Ctrl+O`, `Enter`. Выйти: `Ctrl+X`.

### 4. Запустить

```bash
docker compose up -d --build
```

Первый раз собирается 2–4 минуты. Проверка:

```bash
docker compose ps
```

Все три сервиса (`caddy`, `web`, `worker`) — в состоянии `running` / `Up`.
Откройте в браузере адрес из `SITE_DOMAIN` (например `https://31-130-132-118.sslip.io`).
Сертификат получается в первую минуту — если браузер сразу ругается, подождите и обновите.

## Вход по почте (Яндекс)

1. Заведите отдельный ящик на Яндексе, например `odinplusodin.poisk@yandex.ru`.
2. Яндекс ID → «Безопасность» → «Пароли приложений» → «Почта» → создать. Скопируйте пароль.
3. На сервере впишите в `.env` `SMTP_USER=<ящик>` и `SMTP_PASSWORD=<пароль приложения>`
   и выполните `docker compose up -d`.

## Свой домен (когда появится)

1. У регистратора домена добавьте запись **A** → `31.130.132.118`
   (для поддомена — имя поддомена, для самого домена — `@`).
2. На сервере: `cd /opt/1plus1 && nano .env` → `SITE_DOMAIN=ваш-домен.ru`
3. `docker compose up -d` — Caddy сам получит сертификат на новый адрес.

## Каждый день

Сначала зайти в папку проекта: `cd /opt/1plus1`

| Что нужно | Команда |
|-----------|---------|
| Что делает worker | `docker compose logs -f --tail 50 worker` (выход — `Ctrl+C`) |
| Обновить после изменений на GitHub | `git pull && docker compose up -d --build` |
| Применить изменения в `.env` | `docker compose up -d` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Копия базы | `cp data/strely.db data/strely-$(date +%F).db` |
| Статистика | `curl -s http://127.0.0.1:8090/api/stats` |

В логах worker каждые полторы минуты строка вида
`цикл: {'new_messages': 12, 'processed': 12, 'geocoded': 3, 'archived': 0}`.

Объект пропадает из поиска, если его не присылали 45 дней (`STALE_DAYS` в `.env`).
