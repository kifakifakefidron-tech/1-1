# Таблица «1+1 · сообщения по запросам» — инструкция

Скрипт: [Code.gs](Code.gs). Сам ничего не отправляет — только готовит текст.

## 1. Установка (5 минут, один раз)

1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1R_Dm7qSgVKsBttCdH8MtTQb2AURspSWAsQIvwAkBgoE/edit
2. Меню **Расширения → Apps Script**. Откроется редактор в новой вкладке.
3. Слева файл `Код.gs` (или `Code.gs`). Выделите всё в нём (Ctrl+A), удалите.
4. Откройте у себя файл `Code.gs`, скопируйте всё (Ctrl+A, Ctrl+C) и вставьте в редактор (Ctrl+V).
5. Нажмите значок дискеты **«Сохранить»** (или Ctrl+S). Название проекта — любое, например «1+1».
6. Вверху в списке функций выберите **setupSheet** → нажмите **«Выполнить»**.
7. Google попросит разрешение: **«Предоставить доступ» → выберите свой аккаунт → «Дополнительные настройки» →
   «Перейти на страницу 1+1 (небезопасно)» → «Разрешить»**. Это нормально: скрипт ваш, Google так пишет про
   любой скрипт, который не проверял сам. Скрипт работает только с этой таблицей.
8. Вернитесь во вкладку с таблицей и обновите её (F5). Появится меню **«1+1»** справа от «Справка»,
   листы **«Запросы»**, **«Настройки»**, **«Лог»**.

> Если на первом листе уже были ваши данные, скрипт создаст отдельный лист «Запросы» и не тронет старый.
> Проверьте в редакторе: **Настройки проекта (шестерёнка) → «Включить среду выполнения V8»** — галочка должна стоять
> (у новых проектов стоит сама).

## 1а. Новые запросы с сайта — сами (один раз настроить)

Таблица каждые 15 минут сама забирает с сайта 1+1 новые запросы покупателей из чатов, добавляет их строками
внизу листа «Запросы» и сразу готовит сообщения. В K пишется «с сайта, запрос №…».

Что приходит: только запросы с номером телефона. Не приходят номера тех, кто **уже пользуется 1+1**
(подтверждённые номера агентов и номера аккаунтов), кто просил скрыть номер, удалённые вами, и свои
(СТРЕЛЫ, поддержка). Номер, который уже есть в таблице, второй раз не добавляется. Телефон из текста
запроса убирается — он в колонке B, а в цитату в сообщении не попадает.

**На сервере** (один раз):

1. Придумать ключ — длинный набор букв и цифр. Проще всего на сервере:
   ```bash
   openssl rand -hex 24
   ```
   Скопируйте то, что выведется (48 знаков).
2. Вписать его в `.env`:
   ```bash
   nano /opt/1plus1/.env
   ```
   Добавить строку `EXPORT_KEY=ваш_ключ`, сохранить (Ctrl+O, Enter, Ctrl+X).
3. Обновить сайт:
   ```bash
   cd /opt/1plus1 && git pull && docker compose up -d --build
   ```

**В таблице** (один раз, после того как вставили новый Code.gs):

1. **1+1 → Ключ сайта…** → вставить тот же ключ → OK. Ключ хранится в свойствах скрипта, на листах его не видно.
2. **1+1 → Автозабор с сайта: включить (каждые 15 мин)**. Google попросит ещё одно разрешение
   («подключение к внешним сервисам» и «запуск по расписанию») — разрешите так же, как в шаге 7 выше.
   Сразу будет первый забор: в первый раз берутся запросы только за последние 3 дня (меняется на листе
   «Настройки» → «Первый забор: запросы за дней»), дальше — все новые.

Забрать вручную в любой момент — **1+1 → Забрать новые запросы с сайта**. Выключить —
**1+1 → Автозабор с сайта: выключить**. Работает, даже когда таблица закрыта.

Если что-то не так — смотрите лист «Лог»: «Сайт не принял ключ (403)» — ключи в таблице и в `.env` разные;
«Выгрузка на сайте выключена (404)» — в `.env` нет `EXPORT_KEY` или сайт не обновлён.

## 2. Как работать

1. Вносите в лист **«Запросы»**: A — Имя, B — Телефон, C — Источник, D — Запрос.
2. Как только в строке есть Запрос, сообщение появится само (E–H заполнятся, статус «Готово», дата).
   Имя не обязательно: без него — «Здравствуйте!» / «Добрый день.» без обращения, в K — «без имени».
   Вписали имя позже (пока статус «Готово») — сообщение само пересоберётся с именем.
   Если вставили много строк сразу или автогенерация выключена — **1+1 → Сгенерировать сообщения**.
3. Отправка: **1+1 → Отправка по очереди (панель)**. Справа откроется панель:
   - «Скопировать текст» — в буфер; для MAX найдите человека по номеру и вставьте;
   - «Открыть WhatsApp с текстом» — откроется чат с этим номером, текст уже вписан;
   - «Скопировать и открыть Telegram» — чат по номеру (если человек разрешил поиск по номеру);
   - **«Отправлено → следующий»** — статус «Отправлено», дата, и сразу следующая строка;
   - «Пропустить», «Отказ», «Другой вариант текста».
4. Ответил человек — поставьте в колонке I «Ответил» (выпадающий список).

### Меню «1+1»

| Пункт | Что делает |
|---|---|
| Сгенерировать сообщения | Все новые строки (есть Запрос, статус пустой) |
| Сгенерировать выбранную строку | Только выделенные; «Готово» не перезаписывает |
| Перегенерировать выбранную строку | Новый вариант текста даже поверх «Готово» |
| Отправка по очереди (панель) | Копировать / открыть WhatsApp, Telegram / отметить |
| Отметить выбранные «Отправлено» | Если отправили, не открывая панель |
| Забрать новые запросы с сайта | Сразу, не дожидаясь расписания |
| Автозабор с сайта: включить / выключить | Каждые 15 минут сам |
| Ключ сайта… | Ввести EXPORT_KEY с сервера |
| Очистить готовые | Очищает E–H у «Готово» (статус и дата тоже — строка снова «новая») |
| Подготовить таблицу | Шапка, ширина колонок, список статусов, цвета |
| Настройки | Открывает лист «Настройки» |

### Что скрипт не трогает никогда

| Статус в колонке I | Сгенерировать | Перегенерировать | Очистить готовые |
|---|---|---|---|
| пусто | да | да | — |
| Готово | нет (если текст уже есть) | **да** | да |
| Отправлено, Ответил | нет | нет | нет |
| Отказ, Повтор номера | нет | нет | нет |
| любой свой («позвонить» и т. п.) | нет | нет | нет |

Строки без Запроса пропускаются молча. Без Имени — сообщение готовится, просто без обращения по имени.

**Повтор номера** (моя добавка): если этому номеру уже есть строка с любым статусом — новая строка получает
«Повтор номера», а в K пишется «этому номеру уже писали: строка N». В сообщении обещаем «пишу один раз» —
скрипт помогает это обещание сдержать. Номера сравниваются по цифрам: `+7 918 111-22-33` = `89181112233`.
Выключается в «Настройках».

## 3. Пример: 4 строки

| A Имя | C Источник | D Запрос | E Ключевые слова | F Строка поиска | H | I |
|---|---|---|---|---|---|---|
| Ольга АН Этажи | MAX ФМР чат | 2к фмр до 7 млн | 2к, фмр, до 7 млн | 2к фмр до 7 млн | ~850 | Готово |
| Иван | TG Риелторы Краснодар | ищу дом с участком в ЮМР до 15 млн | дом, участок, юмр, до 15 млн | дом участок юмр до 15 млн | ~860 | Готово |
| Анна | WA Агенты ЮМР | студия в ЖК Панорама до 5 млн | студия, жк панорама, до 5 млн | студия жк панорама до 5 млн | ~850 | Готово |
| Сергей | MAX Коммерция КРД | коммерция, помещение 60-80 м2 в центре | коммерция, помещение, 60-80 м2, центр | коммерция 60-80 м2 центр | ~860 | Готово |

Длина каждый раз немного разная: текст собирается из синонимов (из 2000 запусков на одной строке — 2000 разных текстов).
Скрипт понимает и сложнее: «Двушка в Гидрострое до 7000000, не первый и не последний этаж, ипотека» →
`2к гмр до 7 млн не первый этаж не последний этаж ипотека`; «сниму однушку ФМР до 40 тыс с мебелью» →
`аренда 1к фмр до 40 тыс с мебелью`; «евродвушка от 50 кв.м в Школьном» → `евро2 от 50 м2 школьный`.

Колонка G для строки «Ольга» (один из вариантов):

```
Ольга, здравствуйте! Увидел в группе «ФМР» ваш запрос «2к фмр до 7 млн». Это единственное сообщение: если не актуально, просто не отвечайте, больше не побеспокою.

Мы запустили 1+1 для риелторов, чтобы не читать сотни чатов руками. Сервис сводит объявления из MAX, Telegram и WhatsApp в одну базу с поиском. В базе 10 000+ объектов: квартиры, дома, участки, коммерция. Искать можно как в чате, например ваш запрос: «2к фмр до 7 млн». В каждой карточке — карта, цена за метр и история цены.

Ещё внутри: подборки для клиентов с реакциями «нравится» и «хочу посмотреть», запросы коллег, планер показов и созвонов, уведомления о снижении цены и новых объектах под клиента.

Если решите посмотреть, первые 2 недели бесплатно, без автосписаний. Дальше 399 ₽ за 30 дней. Сайт: https://1plus1assistant.ru

Если не актуально — ничего страшного. Спасибо, что дочитали!
```

Что подставляется само:
- имя — первое настоящее слово («Ольга АН Этажи» → «Ольга», «ИВАН ПЕТРОВИЧ» → «Иван Петрович»); не нашлось — просто «Здравствуйте»;
- чат — без «MAX/TG/WA» и слова «чат» («MAX ФМР чат» → «ФМР»); примерно в 6 из 10 сообщений;
- пример поиска — **запрос самого человека** («например ваш запрос: «2к фмр до 7 млн»»), если он короткий;
- длинный запрос в цитате сокращается до ~120 знаков с «…».

## 4. Обрезка до 900 символов

Полный текст из ТЗ — около **1300 символов**, поэтому при лимите 900 сокращается почти каждое сообщение.
Скрипт идёт по ступеням и берёт первую, которая влезает:

1. полный текст;
2. без блока «По дублям…»;
3. + вместо «Понимаю, что в чатах много сообщений…» — только «Пишу один раз: если не актуально, просто не отвечайте»;
4. + функции одной фразой (подборки, запросы коллег, планер, уведомления — все остаются);
5. + суть сервиса одной фразой (MAX/Telegram/WhatsApp, 10 000+ объектов, поиск как в чате — остаются);
6. + короткий оффер, короткая цитата запроса.

Обычно хватает 3-й или 4-й ступени (выходит 800–900 символов). Приветствие с запросом, оффер (2 недели,
399 ₽, ссылка) и «Если не актуально…» остаются всегда.

Строка после обрезки: **G** — текст как в примере выше, **H** — `850` (фактическая длина), **I** — `Готово`,
**K** — `обрезано до 900`. Если в K был ваш комментарий, пометка добавится через «; » — ваш текст не стирается.

Хотите полный текст с блоком про дубли — поставьте «Лимит символов» = 1400 на листе «Настройки».

## 5. Проверка защиты от повторной отправки

1. В любой строке с готовым сообщением поставьте статус **«Отправлено»**.
2. Запомните текст в G (или скопируйте строку куда-нибудь).
3. Нажмите **1+1 → Сгенерировать сообщения**, затем выделите эту строку и **1+1 → Перегенерировать выбранную строку**.
4. Строка не изменилась; при перегенерации появится окно «строка N: статус «Отправлено» — не трогаю».

То же для «Ответил» и «Отказ». Ещё проверка: добавьте новую строку с тем же телефоном —
она получит «Повтор номера».

## 6. Как выключить автогенерацию

- **Лист «Настройки» → «Автогенерация» → «выкл»** (выпадающий список). Сразу действует. Дальше — только кнопками.
  Удобно перед массовой вставкой: выключили → вставили → «Сгенерировать сообщения» → включили обратно.
- Совсем убрать: в редакторе Apps Script переименуйте функцию `onEdit` (например в `onEdit_off`) и сохраните.
  Это «простой» триггер — в разделе «Триггеры» его нет, он работает по имени функции.

Даже включённая автогенерация не мешает: она срабатывает только на листе «Запросы», только при правке
колонок A или D, только для строк с пустым статусом. Изменения, которые пишет сам скрипт, её не запускают
(так устроен Google), а кнопки и автогенерация не пересекаются — общая блокировка.

## Ошибки

Всё, что пошло не так, пишется в лист **«Лог»**: дата, строка, тип, текст. Хранятся последние 2000 записей.
